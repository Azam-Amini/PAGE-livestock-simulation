# Stochastic Simulation of Gene Editing in Livestock Breeding Programs

This repository contains the complete simulation code and results for the paper:
"Simulating the Benefits and Risks of Gene Editing in Livestock Breeding Programs"

## Contents
- `sim.py`: Main simulation (Python 3.10 + NumPy + Matplotlib)
- `results/`: Saved result arrays (`main.npz`, `sens.npz`, `meta.json`)

## Requirements
- Python 3.10+
- NumPy
- Matplotlib

## Reproduction
```bash
python sim.py
